# Password Manager 🔐 (Desktop App)


---

## 🧠 What is it?

A simple **password manager desktop app** built with **Python**, using:

- `tkinter` for the GUI
- `sqlite3` for local storage
- `pyperclip` for easy clipboard copy
- `random` for secure password generation

The app allows you to:

✅ Generate secure random passwords  
✅ Save and store website login credentials locally  
✅ Search and retrieve credentials by website  
✅ Automatically copy generated passwords to clipboard  

---

## 🛠 Features

- 🔐 Random password generator (mix of letters, numbers, symbols)
- 💾 Save website, username/email, and password to local SQLite database
- 🔎 Search saved credentials by website name
- 📋 Copy password directly to clipboard
- 🖼️ Simple and intuitive GUI (with custom logo)

---

## 🖥 Requirements

- Python 3.x
- Libraries:
  - `tkinter` (standard library)
  - `sqlite3` (standard library)
  - `random` (standard library)
  - `pyperclip` (install via `pip`)
